1. Tổng Quan Kiến Trúc 3 Tầng (3-Tier Pipeline)

Cơ chế lắng nghe thông báo cấp hệ điều hành Android hoạt động qua 3 lớp xử lý:

1
Android Native Service (Kotlin)
Kế thừa NotificationListenerService chạy ngầm 24/7, tự kích hoạt callback onNotificationPosted khi có thông báo mới.
2
Platform Channel (Flutter Bridge)
Dùng EventChannel truyền dữ liệu dạng Reactive Stream độ trễ thấp (<20ms) và MethodChannel điều hướng cấp quyền.

2. Cấu Hình Android Manifest (android/app/src/main/AndroidManifest.xml)

Khai báo Service với quyền bảo mật hệ thống BIND_NOTIFICATION_LISTENER_SERVICE:

AndroidManifest.xml XML 
<application>
    <!-- Đăng ký Service lắng nghe thông báo cấp OS -->
    <service
        android:name=".NotificationMonitorService"
        android:label="chinhan-xT Notification Monitor"
        android:permission="android.permission.BIND_NOTIFICATION_LISTENER_SERVICE"
        android:exported="true">
        <intent-filter>
            <action android:name="android.service.notification.NotificationListenerService" />
        </intent-filter>
    </service>
</application>

3. Triển Khai Kotlin Service (NotificationMonitorService.kt)

Trích xuất nội dung thông báo (Package, Tiêu đề, Nội dung, Timestamp) và gửi vào EventSink:

NotificationMonitorService.kt Kotlin 
class NotificationMonitorService : NotificationListenerService() {
    companion object {
        var eventSink: EventChannel.EventSink? = null
    }
    override fun onNotificationPosted(sbn: StatusBarNotification?) {
        if (sbn == null) return
        val extras = sbn.notification?.extras
        val payload = mapOf(
            "packageName" to (sbn.packageName ?: ""),
            "title" to (extras?.getCharSequence(Notification.EXTRA_TITLE)?.toString() ?: ""),
            "text" to (extras?.getCharSequence(Notification.EXTRA_TEXT)?.toString() ?: ""),
            "timestamp" to sbn.postTime
        )
        eventSink?.success(payload) // Bắn dữ liệu về Flutter ngay tức thì (< 20ms)
    }
}

4. Lắng Nghe Stream Trên Flutter (notification_bridge.dart)

Đăng ký EventChannel để nhận luồng dữ liệu thời gian thực và đẩy vào StreamController:

lib/services/notification_bridge.dart Dart 
class NotificationBridge {
  static const _eventChannel = EventChannel('com.chinhan.xt_manager/events');
  static const _methodChannel = MethodChannel('com.chinhan.xt_manager/methods');

  /// Khởi tạo lắng nghe luồng sự kiện từ Android Native
  void initNativeStream() {
    _eventChannel.receiveBroadcastStream().listen((dynamic event) {
      final map = Map<String, dynamic>.from(event);
      final raw = RawNotification(
        packageName: map['packageName'] ?? '',
        title: map['title'] ?? '',
        text: map['text'] ?? '',
        timestamp: map['timestamp'] ?? DateTime.now().millisecondsSinceEpoch,
      );
      _controller.add(raw); // Đẩy ra UI hoặc Engine Regex bóc tách
    });
  }

  /// Mở màn hình cài đặt cấp quyền hệ thống
  Future<void> openPermissionSettings() async =>
    await _methodChannel.invokeMethod('openSettings');
}

5. Quy Trình Cấp Quyền & Bypass Restricted Settings (Android 13+)

Từ Android 13 (API 33), Google kích hoạt cơ chế bảo vệ chặn bật quyền truy cập thông báo:

⚠️ LƯU Ý BẢO MẬT ANDROID 13+: Khi cài qua file APK tải về (Sideload), nút bật quyền trong "Truy cập thông báo" sẽ bị mờ kèm thông báo "Cài đặt bị hạn chế" (Restricted Settings).
1
Mở khóa Restricted Settings
Vào Cài đặt ➔ Ứng dụng ➔ Chọn chinhan-xT ➔ Nhấn menu 3 chấm góc phải trên ➔ Chọn "Cho phép cài đặt bị hạn chế".
2
Kích hoạt quyền Lắng Nghe
Quay lại mục Quyền truy cập thông báo ➔ Tìm chinhan-xT ➔ Gạt công tắc sang Bật để cấp quyền chạy ngầm 24/7.
